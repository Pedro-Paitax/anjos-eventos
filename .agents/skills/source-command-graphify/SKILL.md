# source-command-graphify

Use this skill when the user asks to run the migrated source command `graphify`.

## Command Template

Execute os seguintes passos para atualizar o mapa de dependências do projeto:
1. Rode no terminal do sistema: `graphify . --code-only`
2. Em seguida: `graphify cluster-only .`
3. Leia as seções atualizadas de `graphify-out/GRAPH_REPORT.md` para guiar suas próximas alterações.
